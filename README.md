# Розроблення VR/AR застосунків

Лабораторні роботи з дисципліни «Розроблення VR/AR застосунків» Пилипчук Вероніки Олексіївни, студентки групи ІМ-33.

## Про проєкт

Усі шість лабораторних робіт виконуються в межах **одного Unity-проєкту**. Наскрізний сценарій — промисловий цех: сцена, створена в першій роботі, послідовно розширюється VR-взаємодією, просторовим інтерфейсом, відстеженням рук та мережевою взаємодією.

## Технології

- **Unity 6.3 LTS** (`6000.3.x`), Universal Render Pipeline (URP)
- **C#** — скрипти логіки та взаємодії
- **Meta XR All-in-One SDK / Unity XR Interaction Toolkit** — VR-взаємодія
- **Meta XR Simulator** — тестування без фізичного шолома
- **Photon Fusion** — багатокористувацький режим (варіант 6.1)
- Цільова платформа: **Meta Quest** (Android Build Support)

## Структура проєкту

```
Assets/
├── Scenes/      сцени проєкту
├── Scripts/     C#-скрипти
├── Prefabs/     префаби об'єктів
├── Materials/   матеріали
└── Settings/    налаштування URP
```

Службові папки Unity (`Library/`, `Temp/`, `Logs/`, `Build/`) виключені з-під контролю версій.

## Робочий процес

Кожна лабораторна виконується в окремій гілці `lab-N`, яка після завершення робіт вливається в `main`. Повідомлення комітів оформлені за конвенцією [Conventional Commits](https://www.conventionalcommits.org/).

## Запуск проєкту

1. Встановити **Unity Hub** та **Unity 6.3 LTS** з модулем **Android Build Support** (разом з OpenJDK та Android SDK & NDK Tools)
2. Клонувати репозиторій:
   ```bash
   git clone https://github.com/namanica/ar-vr-labs.git
   ```
3. У Unity Hub: **Add → Add project from disk** → обрати папку репозиторію
4. Відкрити сцену `Assets/Scenes/Workshop.unity`
5. Натиснути **Play**

Перше відкриття проєкту триває кілька хвилин — Unity генерує папку `Library/`.
